# 01 — 정적 제조 셀과 좌표계

## 목표
공급대·치구·배출대를 배치하고 부모/자식 좌표의 차이를 이해합니다.
로봇 제어와 물리 시뮬레이션은 다음 실습 범위입니다.

## 사전 확인
- Isaac Sim을 실행할 수 있어야 합니다.
- docs/environment.md에 실제 설치 버전을 기록합니다.
- Stage의 길이 단위와 up axis를 확인합니다. 이 실습 좌표는 미터, Z-up 기준입니다.

## 장면 만들기
1. 새 장면에 /World 아래 Xform인 Cell을 만듭니다.
2. Cell 아래 Cube 세 개를 만들고 Supply, Fixture, Output으로 이름을 바꿉니다.
3. 표시 크기와 중심 위치를 아래 표에 맞춥니다. Cube의 기본 size와 scale을 함께 확인합니다.
4. 이 단계에서는 rigid body를 추가하지 않아도 됩니다. 정적 배치 학습입니다.

| 요소 | 크기 X/Y/Z (m) | Cell 기준 중심 X/Y/Z (m) |
| --- | --- | --- |
| Supply | 0.8 / 0.6 / 0.8 | -1.2 / 0 / 0.4 |
| Fixture | 0.6 / 0.6 / 0.8 | 0 / 0 / 0.4 |
| Output | 0.8 / 0.6 / 0.8 | 1.2 / 0 / 0.4 |

이는 실습용 가상 치수이며 실제 설비 사양이 아닙니다.

## 좌표 실험
1. Fixture의 로컬 X를 0에서 0.2로 바꿉니다. 다른 요소도 움직이는지 확인하고 원래 값으로 되돌립니다.
2. Cell의 X를 1로 바꿉니다. 세 요소의 로컬 좌표와 월드 위치를 비교합니다.
3. Cell의 X를 0으로 되돌리고 Z 회전을 90도로 바꿉니다. Supply와 Output의 월드 위치를 예상한 뒤 확인합니다.
4. 실험 후 Cell의 이동·회전을 원래대로 되돌립니다.

## 저장
직접 만든 장면을 이 폴더의 static-cell.usda로 저장합니다.
저장 후 다시 열어 계층, 치수, 위치가 유지되는지 확인합니다.
외부 자산을 참조하면 절대경로 의존성과 배포 권한을 확인하고 출처를 기록합니다.
