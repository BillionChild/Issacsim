# 엔진 픽업 이상 상황: 영상 인식과 위치 보정 설계안

상태: 구현 전 검토안. 기존 정상/수동 출고 데모는 유지한다.

## 목표와 현재 상태

파렛트와 고정된 엔진의 정차 오차를 카메라로 관측하고, 추정 위치로
로봇 접근 경로를 보정한다. 정상·단일·복합 조건을 같은 기준으로 평가한다.
현재 Vision/Camera는 외형 박스이고 u_storage.py는 고정 PICK 좌표와
사전 계산한 경로를 사용한다. 영상 센서, 인식기, 온라인 경로 생성은 신규 작업이다.

## 네 가지 독립 조건

1. 진행 방향 정차 오차: 픽업 구간의 컨베이어 진행 방향 X 이동.
2. 횡방향 치우침: 컨베이어 폭 방향 Y 이동.
3. 평면 회전: 파렛트 중심 기준 Z축 회전. 엔진과 지지핀도 함께 회전.
4. 관측 불량: 파렛트 기준 특징 일부가 가려지는 영상 조건.

오차 크기는 실제 공차가 아닌 실험 매개변수다. 컨베이어 지지 범위와
그리퍼 간섭 확인으로 허용 범위를 정하며, 문서 단계에서 임의 치수를 확정하지 않는다.
관측 불량은 실제 장면 가림 또는 영상 마스크로 만들고 어느 방식인지 기록한다.
엔진의 고정핀 이탈, 기울어짐, 중량 검증은 이번 범위에 포함하지 않는다.

## 시험 구성

정상, X, Y, 회전, 관측 불량의 단일 시험 5개와
X+Y, X+회전, Y+회전, X+Y+회전, 위치 오차+관측 불량의 복합 시험을 둔다.
복합 조건은 동일한 파렛트 중심 변환에서 합성한다. 고정 시드로 재현하고
보정 가능/범위 초과 조건을 분리한다. 정상 자동 데모와 별도 모드로 시작한다.

## 인식 방식과 데이터 경계

권장: 픽업 구간 고정 RGB-D 카메라 + 학습 기반 파렛트 기준점 검출 +
카메라 보정값/깊이를 이용한 XY·yaw 추정. 엔진이 고정핀에 정상 안착했다는
조건에서 알려진 지그 상대 위치로 엔진 픽업 자세를 계산한다.
기준점의 실제 가시성은 렌더 영상으로 확인하고 데이터 생성 전에 확정한다.

대안: 마커·기하 영상처리는 빠른 기초 검증용이나 이것만으로 학습형 AI라
표현하지 않는다. 엔진 전체 6D 자세 추정은 데이터와 개발 범위가 커 이번엔 제외한다.
학습 모델/의존성은 기존 환경과 GPU 여유를 확인한 뒤 선택한다.

이상 주입기는 정답 변환을 장면에 적용한다. 인식기는 RGB/깊이와 카메라
보정값만 입력받고, 정답 위치·사례 ID·USD 엔진 변환은 읽지 않는다.
정답은 데이터 라벨링과 분리된 평가기에만 사용한다. 검증 데이터의 위치·조명·
가림 조합은 학습 데이터와 분리한다. 신뢰도는 임의 퍼센트가 아닌 모델 점수와
기하 일관성 지표를 구분해 표시하고 검증 데이터로 기준을 정한다.

## 대응과 성공 판정

정차 -> 새 영상 확인 -> 특징 검출 -> 자세 추정 -> 신뢰도/보정 범위 판단
-> IK와 경로 간섭 검사 -> 접근/집기/상승 -> 영상 재확인 -> 보관.

관측 불량은 두 번까지 재촬영한다. 지속되면 로봇은 접근하지 않고 작업자에게
가림 제거를 요청한다. 가림 제거 후 새 영상으로 다시 판단한다.
보정 범위 초과 또는 경로 실패도 픽업을 차단하고 재정렬 요청 상태로 둔다.
실제 재정렬 장치가 없는 상태에서 파렛트를 정상 위치로 순간 이동해 복구했다고
표현하지 않는다. 작업자 보완과 자동 보정의 성공률은 별도로 기록한다.
위치 오차는 새 목표로 경로를 계산하며 기존 궤적 전체를 단순 평행 이동하지 않는다.
모델 시간과 렌더 프레임을 동기화하여 오래된 영상으로 움직이지 않도록 한다.

현재 파지는 운동학적 부착이므로 성공은 위치 추정·경로 실행·영상 확인의 성공이다.
접촉력이나 실제 파지 안정성을 검증했다고 주장하지 않는다.

## 구현 순서 및 확인 기준

1. 픽업 카메라와 4조건 재현: 원본 데모 유지, 단일/복합 렌더 이미지 확보.
2. 데이터 생성 및 인식 검증: 정답 유출 방지, 미학습 조건 위치/각도 오차 보고.
3. 추정 자세 기반 픽업: 관절 제한/간섭 확인, 부착 순간 위치 점프 검사.
4. 복구 상태와 현황판: 이미지, 추정 오차, 판단 근거, 재시도, 개입 여부 표시.
5. 반복 평가: 정상 대비 성공률, 잘못된 픽업 허용 수, 추가 소요 시간 비교.

구현 전 확인 대상: 위 네 조건의 선정과 픽업 구간 RGB-D 카메라 추가.
모델 학습이나 대량 렌더링은 단계별 작은 샘플 검증 뒤 진행한다.
